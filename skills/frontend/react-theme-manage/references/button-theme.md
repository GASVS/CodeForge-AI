## Button‑theme decision table

| Condition | Dark Mode Class | Light Mode Class |
|---|---|---|
| Enabled | `bg-indigo-600 text-white hover:bg-indigo-700` | `bg-slate-200 text-gray-800 hover:bg-slate-300` |
| Disabled | `opacity-50 cursor-not-allowed` | `opacity-50 cursor-not-allowed` |

Use `!input.trim()` to decide disabled state.
